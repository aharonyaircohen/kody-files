# Code of conduct

We want this project to be welcoming and useful to contributors of different backgrounds and experience levels.

Be respectful, assume good intent, and focus feedback on code and behavior. Harassment, personal attacks, and sharing another person's private information are not acceptable. Maintainers may edit or remove comments, close discussions, or restrict participation when needed to protect the community.

For a conduct concern, open an issue with a brief request for a private contact channel and leave out personal details. A maintainer will arrange a private follow-up. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
